# Fontes locais

Baixe e coloque aqui os arquivos `.woff2`:

- `JetBrainsMono-Regular.woff2`
- `JetBrainsMono-Medium.woff2`
- `InstrumentSerif-Regular.woff2`
- `InstrumentSerif-Italic.woff2`

Fontes gratuitas (SIL Open Font License), fáceis de obter:
- JetBrains Mono: https://www.jetbrains.com/lp/mono/ → baixe o zip e converta os `.ttf` para `.woff2` (usando https://transfonter.org/) ou copie os `.woff2` já disponíveis no pacote oficial.
- Instrument Serif: https://fonts.google.com/specimen/Instrument+Serif → mesmo processo.

Se os arquivos não existirem, o dashboard cai no fallback (monospace do sistema + serif do sistema) e continua funcional — apenas perde a identidade tipográfica do "Terminal Editorial".
